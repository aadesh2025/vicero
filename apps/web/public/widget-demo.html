A plain HTML page

This static page has nothing to do with Vicero except one <script> tag at the bottom. The chat bubble in the corner is the embedded widget, talking to the public API — Shadow-DOM isolated, so none of this page's styles leak into it (or vice-versa).

Make it live in 3 steps

  1. In the dashboard, open a published agent → Channels tab, and copy its public key.
  2. Edit the <script> tag below: set data-agent to that public key, and data-api to your API host (http://localhost:8000 in dev).
  3. Reload. The launcher bubble appears; click it and chat.

This file ships with data-agent="pk_replace_me" as a placeholder — the widget will log "could not load widget config" until you swap in a real, published agent's public key. The public key is safe to expose in client-side HTML.

The embed snippet

<script
  src="http://localhost:3000/widget.js"
  data-agent="pk_your_agent_public_key"
  data-api="http://localhost:8000"
  defer></script>
